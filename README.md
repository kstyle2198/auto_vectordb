# Project : Auto VectorDB

- Quick and Automated Data Pipeline to make VectorDB for PoC or Prototype Agent Project
- Including File process, Parsing process, Embedding Process, ElasticSearch Indexing Process, etc
- Background Task for time consuming Parsing Process using Celery, Redis
